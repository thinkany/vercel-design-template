# Installing thinkany design

A quick, one-time setup. Takes about two minutes.

## Before you start

- **A Mac with Apple Silicon** (M1, M2, M3, or M4 — any Mac from ~2020 on).
  *On an older Intel Mac? Let us know and we'll send an Intel build.*
- **An Anthropic API key** — the app uses it to power the design assistant.
  Get one at **[platform.claude.com](https://platform.claude.com)** → *API keys*.
  (Usage is billed to that account; a little goes a long way.)

## 1. Install the app

1. Double-click **`thinkany design-0.0.1-arm64.dmg`**.
2. In the window that opens, **drag the `thinkany design` icon onto the
   Applications folder**.
3. Eject the disk image (drag it to the Trash / click ⏏), and open your
   **Applications** folder.

## 2. First open (one-time security step)

This app isn't yet signed with Apple, so the very first launch needs one extra
click to tell macOS it's safe. **You only do this once.**

1. **Double-click** `thinkany design` in Applications. macOS will say it
   "cannot be opened because it is from an unidentified developer" (or that it's
   "damaged"). That's expected — click **Cancel / OK**.
2. Open **System Settings → Privacy & Security**.
3. Scroll down to the **Security** section — you'll see a line about
   *"thinkany design" was blocked*. Click **Open Anyway**.
4. Confirm with **Open** (and Touch ID / your password if asked).

That's it — from now on it opens with a normal double-click.

> Older tip that still sometimes works: **right-click** the app → **Open** →
> **Open**. If your Mac doesn't offer that, use the Settings steps above.

## 3. Set it up

When the app opens:

1. **Paste your Anthropic API key** when prompted, and click to save it. (It's
   stored securely in your Mac's keychain — never in your projects.)
2. **Say hello** — the assistant kicks off a guided setup to brand your first
   design project. Just follow along.

## Where your work lives

The app asks you to pick a **folder for each project**. Your designs are saved
there as normal files — nothing is locked inside the app. Back that folder up
like any other work.

## Trouble?

- **"damaged and can't be opened"** → it's the unsigned-app warning from step 2;
  use **Privacy & Security → Open Anyway**.
- **The preview stays blank** → give it a few seconds on first launch; it builds
  a fresh project the first time.
- **Anything else** → send a screenshot and what you were doing, and we'll sort
  it out.
